# Successful-enable fixture

This repository source is a minimal `JavaPlugin` with no custom runtime behavior, used to exercise a successful plugin discovery and enable path on a real Paper server.

`../PluginMatrixSmoke.jar` is built from the adjacent Java source and `plugin.yml` by `../build_fixtures.py`. It is test-only and must not be installed on a production server.

Repository provenance is documented in `../README.md`; the project owner confirmed Apache-2.0 release rights for v0.5.0.
