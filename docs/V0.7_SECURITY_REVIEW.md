# v0.7 focused security review handoff

Baseline: `fea081a`, branch `codex/v0.7-local-web-ui`. The owner narrowed the
review on 2026-09-14 to essential fixes and local checks; remaining standalone
and hosted work is deferred to the next agent. This is **not** release approval.

## Fixed

- P1: HTTP workers were unbounded, inactivity timeouts could be extended by
  trickling bytes, and shutdown waited for request threads before cancelling
  verifier jobs. Bound connections to 32, enforce a 30-second absolute connection
  deadline, interrupt active sockets on close, and cancel jobs before draining.
- P1: Uploads held the global job lock while reading the network, blocking job
  operations and shutdown. Reserve file count/bytes under the lock, perform I/O
  outside it, and cap session uploads at 2 GiB including in-flight reservations.
- P2: Ambiguous framing/duplicate security headers and unread bodies could be
  reused as subsequent requests. Reject duplicate/folded security headers,
  Transfer-Encoding, Expect and GET bodies; serve one request per connection.
  Validate supplied Origin on GET as well as POST.
- P2: Artifact registration resolved symlinks before rejecting them; downloads
  accepted equal-length in-place modifications and could block on a raced FIFO.
  Reject links before resolution, compare descriptor/name identities and file
  timestamps, reject hardlinks/non-regular files, open nonblocking/no-follow where
  supported, and never send beyond the registered Content-Length.
- P2: Configuration size checks preceded an unbounded reopen/read. The shared
  parser now reads at most 1 MiB + 1; Web imports pass a verified open descriptor.
- P2: Standalone JAR rejection happened after archive/checksum creation, and
  recursive Web resource collection could include unrelated local files.
  Resource collection now explicitly selects the three UI assets; an audit
  rejects runtime/private filenames, special files and escaping links before
  archive creation. Internal native-library symlinks remain supported.

Regression tests cover raw HTTP framing/pipelining, partial-header deadlines and
shutdown, worker capacity, upload locking/quota, artifact mutation/links and
configuration descriptor consumption. Runtime verdict and Provider logic are unchanged.
